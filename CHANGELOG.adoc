==== Added

* Repository initialised from the RSR template (`just repo-init`), with
  the deed's clade (`dx`, secondary `pt`, `sc`) and identity filled.
* ADR 0004: BoringSSL chosen over Zig std, Mbed TLS and wolfSSL.
* `src/interface/ffi/`: hash-pinned BoringSSL built by `build.zig`; the
  typestate TLS client wrapper; loopback tests, FFI drift check and
  mutation check; per-build test fixtures (no committed keys).
* `Zig CI` workflow; Wolfi-based build-and-test container.
* Security notes for the wrapper (`docs/security/TLS-WRAPPER-SECURITY.adoc`).
