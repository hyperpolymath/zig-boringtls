A thin, typestate Zig wrapper over https://boringssl.googlesource.com/boringssl/[BoringSSL]
for TLS 1.3 clients: DoH (ALPN `h2`), Gemini (trust-on-first-use pinning) and
client certificates, with DoQ reachable later through the same library.

It is *not* a TLS implementation. The cryptography, protocol and X.509
validation are BoringSSL's. This code decides which checks run, makes the TOFU
decision, and turns results into explicit Zig errors.

* *Why BoringSSL:* link:docs/decisions/0004-tls-library-for-zig.adoc[ADR 0004]
  compares Zig std, BoringSSL, Mbed TLS and wolfSSL, and covers why Zig std
  (0.17.0) is unsuitable today.
* *What is and isn't guaranteed:*
  link:docs/security/TLS-WRAPPER-SECURITY.adoc[the wrapper's security notes].
  It has not been externally reviewed; please read them before relying on it.

== Layout

The Zig package lives in `src/interface/ffi/` (the estate's FFI location):

[cols="1,3"]
|===
| Path | What lives there

| `src/interface/ffi/build.zig`, `build.zig.zon` | Builds the hash-pinned BoringSSL from its `gen/sources.json` with Zig's toolchain (no CMake, Go or Perl), then the wrapper and tests.
| `src/interface/ffi/src/root.zig` | The wrapper: `connect`/`fromFd` -> `Connection` -> `handshake()` -> `Session`.
| `src/interface/ffi/src/c.zig` | Hand-written BoringSSL declarations, checked against `translate-c` by `tests/ffi_drift.zig`.
| `src/interface/ffi/tests/` | 30 loopback handshakes against an in-process BoringSSL server, plus the FFI drift check.
| `src/interface/ffi/scripts/` | Per-build fixture generator, mutation check, drift self-test, Zig std probe.
| `build/container/Containerfile` | Wolfi-based build-and-test image.
|===

== Requirements

* Zig *0.17.0* exactly (the std and build APIs differ between releases).
* `bash` and OpenSSL 3.x for the per-build test fixtures.
* No system OpenSSL headers, CMake, Go or Perl.
* Tested on x86_64-linux only. Other targets are configured but untested;
  non-ELF and non-x86_64/aarch64 targets build without assembly.

== Use

[source,zig]
----
const tls = @import("boringtls");

// DoH-style: WebPKI chain to the roots you name, plus SAN hostname check.
var conn = try tls.connect(io, "dns.example", 443, .{
    .server_name = "dns.example",
    .trust = .{ .webpki = .{ .roots_pem_file = "/etc/pki/tls/certs/ca-bundle.crt" } },
    .alpn = &.{ "h2", "http/1.1" },
});
var result = try conn.handshake(); // consumes conn; on error, see conn.diagnostic()
var s = switch (result) {
    .established => |session| session,
    .first_use => unreachable, // WebPKI cannot produce first-use trust
};
defer s.close() catch {};
try s.writeAll(request);
const n = try s.read(&buf); // 0 only on close_notify; error.Truncated otherwise
----

[source,zig]
----
// Gemini-style TOFU: pin = SHA-256 of the leaf's SubjectPublicKeyInfo.
var conn = try tls.connect(io, host, 1965, .{
    .server_name = host,
    .trust = .{ .tofu = .{ .known_pin = store.get(host, 1965) } }, // ?Pin
    .min_version = .tls1_2, // many capsules still run TLS 1.2 (ECDHE+AEAD only)
});
var result = conn.handshake() catch |e| switch (e) {
    error.PinMismatch => return warnUser(conn.observedPin()), // unauthenticated claim
    else => return e,
};
var s = switch (result) {
    .established => |session| session, // the stored pin matched
    .first_use => |pending| blk: {
        defer pending.deinit(); // releases the opaque handle after transfer
        const pin = pending.presentedPin();
        try store.put(host, 1965, pin); // persist before enabling application I/O
        break :blk try pending.acknowledgePersistedPin(pin);
    },
};
defer s.close() catch {};
----

Client certificates: set `.client_identity = .{ .chain_pem_file = ..., .key_pem_file = ... }`.
Under TLS 1.3 a server that _rejects_ the certificate does so after the
handshake, so the error appears on the first `read`.

Certificate inspection: `s.peerCertificate()` returns the leaf DER,
`sha256Fingerprint()`, `spkiPin()`, `validity()`, `subject()`, `issuer()` and
the chain length. DN helpers return `error.BufferTooSmall` rather than a
truncated name when the supplied output buffer cannot hold the whole result.

== Build and test

[source,bash]
----
just test                                   # runs `zig build test` in src/interface/ffi/
cd src/interface/ffi
zig build test --summary all                # 38 tests: unit, 30 loopback handshakes, FFI drift + socket-mode guard
./scripts/mutation-check.sh                 # re-introduces each misuse; the suite must fail
./scripts/ffi-drift-selftest.sh             # injects FFI drift; the build must fail
./scripts/probe-std-basic-constraints.sh    # shows ziglang/zig#35877 in Zig std
podman build -t zig-boringtls-test -f build/container/Containerfile . \
  && podman run --rm --network=none zig-boringtls-test
----

The `Zig CI` workflow runs the format check, Debug and ReleaseSafe tests, the
drift self-test and the mutation check on every pull request.

`just test` also detects the template's Idris2 ABI scaffold
(`src/interface/abi.ipkg`) and needs `idris2` for it; that seam is not yet
filled for this library.
