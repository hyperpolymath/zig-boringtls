= Formal Verification Proofs

Which prover carries which obligation is set estate-wide by
`3-practice/PROOF-POLICY.adoc` in `metadatastician/standards`. Read it there;
this page maps it onto this repository.

zig-boringtls has *engineering* obligations only (PROOF-POLICY §1), so its
prover is Idris2. The obligations are listed in
`docs/status/PROOF-NEEDS.adoc` and the per-claim results in
`docs/status/PROOF-STATUS.adoc`.

== Where the proofs live

[cols="1,2",options="header"]
|===
| Path | Contents

| `src/interface/Abi/` (package `src/interface/abi.ipkg`)
| The handle-lifecycle contract as linear types (issue #11): `Tls.idr` (the
contract), `Client.idr` (positive control), `Misuse.idr` (`failing` blocks
that must be rejected). They live with the ABI seam, not here, because they
are the interface itself.

| `verification/proofs/idris2/MANIFEST`
| Gates the modules above: `scripts/check-proofs.sh idris2` checks every
listed module from its source root and fails on any `.idr` file under a
listed root that is not listed.
|===

There are no Agda, Rocq, Lean or TLA+ files: nothing here is a theory
obligation, and the template's sample proofs were removed because they proved
nothing about this code.

== Verification commands

[source,bash]
----
just proof-check-idris2
(cd src/interface && idris2 --typecheck abi.ipkg)
----

`just proof-check-all` also runs the Agda, Rocq and Lean checks; with no
proofs and no MANIFEST for a prover, that check reports "nothing to check"
instead of requiring the toolchain.

== Banned patterns

`believe_me`, `assert_total`, `postulate`, `sorry`, `Admitted`,
`unsafeCoerce` and `Obj.magic` must not appear in a proof file. Idris2 modules
use `%default total`.
