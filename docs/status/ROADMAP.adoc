= zig-boringtls Roadmap

== Current status

Incubating (deed `(status)`), maturity experimental. The wrapper, its
tests, the FFI drift check and the mutation check exist; a passing CI run is
required before treating them as verified. See `README.adoc` §Status for what
is TESTED versus OPEN.

== Milestones

=== v0.1.0 — first usable cut
* [x] BoringSSL built from `build.zig`, hash-pinned (ADR 0004)
* [x] Typestate client API: WebPKI, TOFU pinning, client certificates, ALPN
* [x] Loopback handshake tests, FFI drift check, mutation check
* [x] Security notes (`docs/security/TLS-WRAPPER-SECURITY.adoc`)
* [ ] `Zig CI` green on GitHub (also confirms the BoringSSL package hash)
* [ ] Run BoringSSL's own `crypto_test` / `ssl_test` against this build
* [ ] Interop tests against OpenSSL `s_server`, a real Gemini capsule and DoH endpoints

=== v0.2.0 — DoQ
